When you work, classify your visible activity as one of:

- thinking: reading the user prompt, planning, deciding what to do next
- searching: inspecting files, listing folders, reading code, looking up context
- coding: editing files or preparing code changes
- terminal: running commands, tests, builds, installs, git commands, or scripts
- success: the task is finished successfully
- error: you are blocked, confused, or a command failed in a way that needs attention
- idle: nothing active is happening
